Firebase 실시간 연결

Firebase 프로젝트 설정을 넣으면 같은 프로젝트와 채널 ID를 사용하는 참가자들의 기록이 실시간으로 함께 표시됩니다.

연결 전 · Firebase 설정이 이 브라우저에 저장됩니다.
Firebase 프로젝트 준비 안내
  1. Firebase Console에서 웹 앱을 등록하고 설정 JSON을 복사합니다.
  2. Authentication에서 익명 로그인을 켜고 Firestore Database를 만듭니다.
  3. Firestore Rules 탭에 아래 규칙을 게시합니다.
  4. 이 HTML을 Firebase Hosting 같은 HTTPS 주소로 배포하고, 그 주소를 다른 참가자에게 공유합니다.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /timer777Rooms/{roomId}/scores/{scoreId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null
        && request.resource.data.uid == request.auth.uid
        && request.resource.data.name is string
        && request.resource.data.name.size() > 0
        && request.resource.data.name.size() <= 20
        && request.resource.data.seconds is number
        && request.resource.data.seconds >= 0
        && request.resource.data.seconds <= 999
        && request.resource.data.chapter in [1, 2]
        && request.resource.data.attempt is int
        && request.resource.data.attempt >= 1
        && request.resource.data.attempt <= 30
        && request.resource.data.success is bool
        && request.resource.data.created is number
        && request.resource.data.keys().hasOnly(['uid','name','attempt','seconds','chapter','success','created']);
      allow update: if request.auth != null
        && resource.data.uid == request.auth.uid
        && request.resource.data.uid == request.auth.uid
        && request.resource.data.name is string
        && request.resource.data.name.size() > 0
        && request.resource.data.name.size() <= 20
        && request.resource.data.seconds is number
        && request.resource.data.seconds >= 0
        && request.resource.data.seconds <= 999
        && request.resource.data.chapter in [1, 2]
        && request.resource.data.attempt is int
        && request.resource.data.attempt >= 1
        && request.resource.data.attempt <= 30
        && request.resource.data.success is bool
        && request.resource.data.created is number
        && request.resource.data.keys().hasOnly(['uid','name','attempt','seconds','chapter','success','created']);
      allow delete: if request.auth != null && resource.data.uid == request.auth.uid;
    }
    match /timer777Rooms/{roomId}/settings/{settingId} {
      allow read: if request.auth != null;
      allow create, update: if request.auth != null
        && settingId == 'successRange'
        && request.resource.data.min is number
        && request.resource.data.max is number
        && request.resource.data.min >= 0
        && request.resource.data.max <= 999
        && request.resource.data.min <= request.resource.data.max
        && request.resource.data.keys().hasOnly(['min','max','updated']);
    }
  }
}

Firebase 웹 설정 값은 공유 링크에 포함될 수 있습니다. 안전성은 Firestore 보안 규칙과 익명 인증으로 보호해야 합니다. 공유 링크의 설정 값은 비밀번호가 아닙니다.
